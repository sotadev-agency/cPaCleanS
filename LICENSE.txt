DESCRIPCION DEL SOFTWARE
------------------------
cPacleanS es una herramienta de seguridad informatica disenada para detectar,
analizar y eliminar malware en copias de seguridad (backups) generadas por el
panel de control cPanel. Permite a administradores de servidores web inspeccionar
y sanear backups de WordPress, Joomla, Moodle y Laravel antes de restaurarlos a
un entorno de hosting limpio.

Funcionalidades principales:
  - Escaneo de malware en PHP, HTML, JavaScript, bases de datos SQL y correos
  - Restauracion de archivos core de CMS desde repositorios oficiales
  - Cuarentena segura con copia de originales antes de cualquier modificacion
  - Generacion de reportes HTML y PDF para documentacion de incidentes
  - Integracion opcional con VirusTotal API para verificacion adicional

ESTE SOFTWARE ES UNA HERRAMIENTA DE SEGURIDAD LEGITIMA. Su unico proposito
es ayudar a los administradores a recuperar sitios web comprometidos de forma
segura y auditable.
